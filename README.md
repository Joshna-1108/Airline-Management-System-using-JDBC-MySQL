✈️ Airline Management System using JDBC & MySQL

About the Project
The Airline Management System is a Java-based application that uses JDBC to connect with a MySQL database and manage flight details efficiently.

Technologies Used
Java  – Application development
JDBC  – Database connectivity
MySQL – Data storage

Features

* Add new flight details
* View all flight details
* Search flights by ID
* Update flight details
* Delete flight records
* Get MetaData

How to Run

1. Clone or download this repository.
2. Create a MySQL database.
3. Create the required `airline` table.
4. Update the database connection details in the Java code.
5. Run the main Java class.

Purpose

This project demonstrates JDBC connectivity, SQL queries, and CRUD operations using Java and MySQL.
